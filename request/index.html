요청·제보한글화 요청, 버그 제보, 개선 의견

한글화했으면 하는 게임, 플레이하다 만난 버그, 고쳤으면 하는 점을 알려 주세요. 보내는 방법은 두 가지입니다.

요청 양식 로그인 필요 없음

구글 설문지로 보냅니다. 보내 주신 내용은 운영자만 봅니다.

요청 양식 열기
  • 버그 제보는 어느 작품·버전에서, 어디서 무엇을 했을 때 생겼는지, 사용한 에뮬레이터를 함께 적어 주시면 빨리 확인할 수 있습니다.
  • 롬 파일이나 다운로드 링크는 보내지 말아 주세요.
  • 모든 요청을 반영하지는 못하는 점 양해 부탁드립니다.

공개 게시판 GitHub 로그인 필요

GitHub 계정이 있으면 여기에 글을 남길 수 있습니다. 글은 누구나 볼 수 있고, 다른 분의 요청에 댓글이나 공감을 달 수 있습니다.

이 패치가 도움이 되셨나요? 후원해 주시면 다음 작품 한글화와 버그 수정을 이어 가는 데 쓰겠습니다.

☕ 후원하기
  • 비공식 팬 번역·패치입니다. 각 게임의 권리는 원 저작권자에게 있습니다.
  • 롬 파일은 배포하지 않습니다. 직접 가진 게임에서 뽑은 롬에 패치를 적용해 주세요.
